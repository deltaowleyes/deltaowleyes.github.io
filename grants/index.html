Funding you can investigate

This directory includes Indigenous-specific funding and wider programs that explicitly accept Indigenous applicants. Search by funding purpose, applicant type, jurisdiction or intake status.

Grants are not the same as loans. Some programs are contributions, bursaries, scholarships or potentially repayable business financing. We label the type so you can verify the terms with the provider.

Before applying

  • Check the original source for the current deadline, time zone and application portal.
  • Confirm identity, Nation, residence, project and organizational eligibility with the provider.
  • Do not send sensitive documents to Delta Owl Eyes; apply directly to the funder.
