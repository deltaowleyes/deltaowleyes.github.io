## Stage-one acceptance
- Six independently navigable demos and a comparison gallery; **six actual pages/views per demo**, not merely six recolours.
- Studio selector and demos are **noindex** and should not be deployed during planning.
- All content explicitly sample or awaiting Brandee; no fabricated biography, rosary prices/inventory, coffee endorsements, Catholic authority, testimonials or achievements.
- Accessible headings, skip link, visible keyboard focus, readable contrast, reduced-motion support; responsive checks at 320, 390, 768, 1024, 1440 and 1920px.
- Screenshot both gallery and each candidate home/mobile, and check every page route, overflow, JavaScript exceptions and assets before approval.
- Preserve all existing Delta Owl Eyes and other-client content; no authentication or database work.
- No external trackers or contact-form collection. The site can reuse existing privacy-control assets only when explicitly hosted.
- QA evidence: tests and visual screenshots required. This initial branch may have **source-level checks only**; absent Chromium evidence must be marked outstanding.
