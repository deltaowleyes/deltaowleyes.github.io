# Brandee's Rosary Road — isolated prelaunch design studio

**Working brand:** Brandee's Rosary Road — *A Beautiful Journey Through Catholic Life.*

This branch-only concept work is not a publicly deployed site. Its files are visible as source code in the public GitHub repository; therefore no private Brandee data is committed. No code in this directory is linked from the production homepage.

- **Plan:** `PLAN.md`.
- **Studio gallery:** `v1/index.html`.
- **Six candidates:** `v1/{cathedral-sunrise,marian-rose-garden,woodland-pilgrimage,rosary-atelier,catholic-journal,coffee-grace}/index.html`.
- **Asset note:** the SVG drawings are original *illustrative placeholders*, not final AI-generated cathedral photography.
- **Behaviour:** each design provides six site views via the URL fragment; no checkout, form or sponsorship is operational.
- **Testing:** run static checks and Chromium QA locally before any merge/deployment. QA is not implied simply by source creation.

No transfer to `main`, preview hosting, domain registration, payment, or public advertising is authorized.
