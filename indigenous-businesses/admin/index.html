2. Review and verify

Only select “Verified” after an authorized business representative confirms the public details being published. Otherwise use “Partially verified” or “Unverified”.

3. Publish through GitHub

Sign into a GitHub account with write permission. Open Edit businesses.json on GitHub, find the exact original business record, replace only that complete JSON object with the copied updated record, and select Commit changes. Check the preview and public profile after deployment.

The original name and city identify the existing record and must stay unchanged in the JSON for its current profile link to keep working. To rename or relocate a business, coordinate a profile-link migration rather than silently changing its identifier.
