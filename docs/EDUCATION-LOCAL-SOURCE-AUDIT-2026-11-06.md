# Education Hub: local original-provider update — November 6, 2026

This is a **simple owner-edited directory update**, not a new submission system or approval committee. It adds **six** public original-source learning entries (30 → 36), retains all previous 30 records, keeps the suppression ledger unchanged, and does not copy teaching media, child records, survivor statements or other restricted cultural material.

## Bkejwanong first

1. **Bkejwanong Kinomaagewgamig elementary school:** Original school site https://www.bkthunderbirds.com/ and Walpole Island First Nation education page https://www.walpoleislandfirstnation.ca/education-department confirm the Bkejwanong community JK–Grade 8 school. **Different from** the already listed Anishinaabeg Kinomaagewgamig immersion school (JK–Grade 6). Admission, grades and current availability require direct confirmation. Catalogue ID `wifn-bkejwanong-kinomaagewgamig`.
2. **Bkejwanong Children's Centre:** https://www.walpoleislandfirstnation.ca/bkejwanong-childrens-centre confirms licensed early childhood and play-based education rooted in Ojibwe language and culture. The source confusingly describes upper ages as "ten (7)"; **no fixed age cut-off was copied**. Tell families to confirm age limits, spaces and fees directly. Catalogue ID `wifn-bkejwanong-childrens-centre`.

## Nearby First Nations

3. **Chippewas of the Thames post-secondary education support:** https://cottfn.com/post-secondary-education-support/ explicitly serves **registered COTTFN members**. Provider lists May 1, October 1 and March 1 application dates and conditional tuition/book/living support. The category is funding; `indigenous-only` in the existing schema is specifically qualified as *registered COTTFN members* in the listing. Do not imply open eligibility or guaranteed funding. ID `cott-post-secondary-support`.
4. **Chippewas of the Thames Anishinaabe’aadziwin:** https://cottfn.com/departments/culture-language-heritage/ verifies language teaching/reclamation, cultural gatherings and heritage learning. No fixed class schedule, public enrollment guarantee or special cultural access is asserted. ID `cott-anishinaabe-aadziwin`.
5. **Kettle and Stony Point Hillside School:** https://kettlepoint.org/kettle-stony-point-education-services/ describes community elementary teaching and Ojibway language/land-based learning across kindergarten–Grade 8. The listing directs families to the school for admissions and current programming. ID `ksp-hillside-ojibway-learning`.
6. **Aamjiwnaang Alternative and Continuing Education:** https://www.aamjiwnaang.ca/education/education-aamjiwnaang-alternative-and-continuing-education-program-aace/ describes Get SET skills training for adults 18+ and the locally supported credit-granting path to an OSSD. Enrolment rules, fees and attendance model remain `check-provider`. ID `aamjiwnaang-adult-learning-aace`.
